# 01 开发任务拆解（M1–M5 + 远期）

> 依据：PRD v1.1 第 23 章分期计划，以及各功能章节。
> - 每个原子任务都标出：**依据**（PRD 章节 / v1.1 编号）、**依赖**、**输入**、**输出**、**验收标准**。
> - 任务 ID 格式为 `M<阶段>-<序号>`。编程智能体应按依赖顺序逐个完成，每完成一个任务，都要跑一遍 `06-测试策略与用例.md` 中对应的用例。
> - 标注 **[阶段分配]** 的任务，PRD 分期表中没有写明属于哪个阶段，阶段是按依赖关系补的，详见 `README.md` 中"PRD 歧义清单"的 A5。

## 通用完成定义（DoD，每个任务都适用）
1. 代码位于 PRD §18.1 规定的包路径下。
2. 新增或修改的配置字段已写入 `pa.config.schema` 并通过 Pydantic 校验。
3. 涉及状态变化的，只能通过 `pa.store.transition()` 完成；涉及对外动作的，只能写入 `effects`。
4. 日志经过打码过滤器（§16.1）。
5. `06` 中对应的测试用例全部通过。
6. 不得引入 PRD 未列出的功能或依赖。
